## 🎯 Objective 1: Be my video production assistant
*An AI assistant that helps run video production end-to-end, driven from Chrome and AI models, using markdown as the source of truth.*

- **KR 1.1:** Help with my video production tasks — research, scripting, transcripts, thumbnails, and publishing support — on request.
- **KR 1.2:** Every workflow this project automates is driven from markdown files in this repo (no hidden state).
- **KR 1.3:** All secrets required (YouTube, AI model, Google, Canva APIs) are pulled from the existing `dp-kv-deliverypilot` Azure Key Vault — zero new vaults, zero secrets committed to git.
